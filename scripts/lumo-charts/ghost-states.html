Working

Seen before

Done

Partial

No page

A 404 or a not-found page stops the check before scoring. A missing page gets no verdict.

Blocked

Thin page

Little to read

The details card says so. Thin details are shown and add no points.

Failed

The run crashed

The check is marked failed, never left “pending”.
